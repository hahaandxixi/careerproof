# CareerProof 演示视频脚本骨架

建议时长 4–5 分钟，最终按官方规则调整。全程使用 `demo/` 合成数据。

| 时间 | 画面 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:25 | 标题与痛点 | 简历技能声明缺少可核对出处，学生也不知道该补什么材料。 |
| 0:25–0:50 | 合成岗位 | 展示 Python、FastAPI、PostgreSQL、pytest、Redis 五项要求和权重。 |
| 0:50–1:25 | 合成材料 | 上传简历与项目 ZIP，展示安全解析、SSE 进度和固定版本。 |
| 1:25–2:00 | 工作流任务页 | 展示材料核对、候选证据检索、规则评分、千问分析、引用校验与保存；说明显示的是执行阶段，不是模型思维过程。 |
| 2:00–3:05 | 带引用报告 | 点击 FastAPI 引用回到路由行；展示 PostgreSQL 仍缺少什么、Redis 只有声明；分数由规则计算，千问不能修改。 |
| 3:05–3:35 | 人工复核 | 采纳一条证据并填写备注，刷新后确认状态仍存在。 |
| 3:35–4:00 | 故障降级 | 展示模型鉴权失败的合成故障任务仍为 100%，任务与报告均明确标注规则降级。 |
| 4:00–4:30 | 评测结果 | 展示 5 个 AI 合成难例、0 个越权引用、五项结构指标 100%，同时说明样本规模限制。 |
| 4:30–4:50 | 隐私与结尾 | 外部模型仅收到岗位要求和候选片段；演示不用真实个人数据，结论不用于自动录用。 |

录制前关闭通知，确认 `.env`、控制台和接口响应不会露出 Key。保留一份已生成的联网报告和一份降级报告，以防现场网络不稳定。
