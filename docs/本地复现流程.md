# 本地生产模式复现

适用Windows PowerShell。需要Python 3.12、Node.js、npm、已启动的Docker Desktop和可用的DeepSeek官方API Key。仓库脚本不购买服务、不写入Key，也不提供主动规则模式。

## 首次安装

```powershell
Set-Location backend
if (!(Test-Path .env)) { Copy-Item .env.example .env }
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
Set-Location ..\jianli
npm ci
Set-Location ..
```

编辑 `backend/.env`：

```dotenv
AI_PROVIDER=deepseek
AI_EXTERNAL_ENABLED=true
DEEPSEEK_API_KEY=仅保存在本机的Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

运行预检和启动：

```powershell
.\Start-Demo.ps1 -CheckOnly
.\Start-Demo.ps1
```

脚本会等待PostgreSQL、迁移到最新schema、构建Next.js、启动两个服务、验证健康状态，并初始化演示账号和九个合成岗位。默认只监听 `127.0.0.1`。缺少DeepSeek配置时启动会失败，不会静默改为规则模式。

## 双端演示流程

1. 使用企业演示账号登录，检查企业组织、岗位发布、岗位要求和岗位管理。
2. 退出企业账号，登录学生账号。
3. 从 `/demo` 下载合成简历和项目ZIP，上传后等待解析完成。
4. 选择“Python后端开发实习生（合成演示）”，选择材料版本并确认AI发送范围。
5. 在任务页观察检索、模型分析、引用校验和保存记录。
6. 在报告页核对模型、Token、逐项评级、引用原文与信息缺口。
7. 保存人工复核备注，刷新并从历史列表找回报告。

企业端只能查看学生明确向本企业岗位投递的固定报告，未授权私有报告仍不可见。完整字段填写和页面路径见 [完整使用手册](完整操作流程.md)。

## 被动规则兜底

产品始终按AI链路发起分析。DeepSeek网络失败、限流、超时、鉴权错误、非法JSON、引用越界、评级越界或一次修正后仍未通过校验时，系统自动保存本地兜底报告。无可发送证据或达到每日用量上限时同样跳过外部请求并保存本地结果。

SSE连接中断只会让前端改用轮询，不等于模型断链。是否发生AI降级以任务步骤和报告标记为准。

## 停止

```powershell
Set-Location ..
.\Stop-Local.ps1 -Database
```

脚本只停止自己记录且身份匹配的前后端进程，停止PostgreSQL容器但保留数据卷。日志与进程记录位于被Git忽略的 `backend/.tmp/local-run/`。
