## 1. 私下保存 Key

用本地编辑器打开 `backend/.env`，在已添加的空字段中填写智谱 Key；不要发到聊天或提交到 Git。保留原百炼 Key 字段即可，两者不会混用。

```dotenv
AI_PROVIDER=zhipu
AI_EXTERNAL_ENABLED=false
ZHIPU_API_KEY=在本机填写你的智谱Key
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_MODEL=glm-4.7-flash
ZHIPU_TIMEOUT_SECONDS=90
AI_WORKFLOW_TIMEOUT_SECONDS=120
ZHIPU_MAX_ATTEMPTS=1
AI_LOCAL_FALLBACK_ENABLED=true
```

这里的变量已经接入项目，不是平台网页上的表单。`.env` 由后端启动时加载，修改后需重启进程。Key 不会交给前端。

## 2. 先验证本地配置，再验证一次真实调用

在 `backend` 目录执行：

```powershell
# 只检查 Key 是否已填写、模型和地址是否允许；不发请求
.\.venv\Scripts\python.exe -m app.scripts.check_zhipu
# 在控制台确认该型号输入/输出免费之后，明确执行一次合成请求
.\.venv\Scripts\python.exe -m app.scripts.check_zhipu --live
```

`--live` 只发一次请求，不自动重试，不发送真实简历或项目文件。输出仅包含模型、JSON 状态等，不打印 Key、模型正文或包含凭据的异常。连接成功并不代表账单为零：需要到智谱控制台核对这次调用费用。
