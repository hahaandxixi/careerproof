# 工具与接入

更新：2026-10-13。本页只保留当前接入与边界；历史调用/失败见[验收汇编](../evidence/历史验收汇编.md)。

## 受控补检索

模型在正式分析前可基于已有检索结果规划有限补证。工具名、参数、岗位要求编号与材料范围由服务端白名单校验；仅检索当前授权版本的索引，不访问网络、不运行代码、不读任意路径。最多两轮规划、有限新片段，最终来源和评级上限仍需校验。

无额外候选、无合法本人历史或预算不足时跳过不必要规划；非法工具/参数拒绝，故障按工作流降级。报告记录工具轮次、范围、新增引用、停止/拒绝/降级状态。它是受约束服务端工具调用，不是通用自主 Agent。

## 本机只读 MCP

| 工具 | 范围 |
| --- | --- |
| `search_evidence` | 已授权报告快照内检索，返回受限脱敏引用 |
| `get_report_summary` | 选定报告摘要、逐项等级与来源 |
| `compare_reports` | 本人同岗位两份已授权报告的变化 |

返回原文件哈希，不应拿脱敏/截断片段冒充原文逐字校验。来源是非可信数据，不能执行其指令。网关仅连接本机 HTTP、无重定向/远程上游，不是公开 OAuth 服务。

1. 登录本人报告，展开「外部工具只读访问（可选）」，选定需读报告。
2. 检查外发说明，明确同意后生成十分钟授权；凭据只在页面内存，不放 URL/仓库/聊天。
3. 将临时凭据通过子进程环境 `CAREERPROOF_MCP_TOKEN` 提供给可信客户端。默认后端 `http://127.0.0.1:8000`，隔离环境应选正确本机地址。
4. stdio 程序是已核验后端 Python 的绝对路径，参数 `-m app.mcp_server`，工作目录为项目 `backend`；使用环境注入，命令参数不放凭据。
5. 用选定报告 ID 调用对应工具，完成后在报告页点击「立即撤销」。刷新隐藏凭据不会提前撤销服务端授权；未撤销的授权最长十分钟、最多 40 次，不自动续期。

可选依赖从当前 `backend/pyproject.toml` 的 `[mcp]` 组安装，先核验解释器与项目兼容环境，再运行 `python -m pip install -e ".[mcp]"` 和 `pip check`。不要照旧教程手工降级 Starlette；本轮锁定为 1.3.1，MCP 为 1.30.0、sse-starlette 为 3.0.3。

每次访问复查当前活跃学生、报告所有权、授权范围/撤销/次数。企业、他人学生和普通登录令牌没有旁路。审计写入独立事件，不保存凭据和完整导出文本。撤销成功后拒绝后续读取，不能追回已经返回给客户端的内容。

外部客户端可能把 MCP 结果再发给其模型商，必须另核对用途与授权。自动过滤不是完整隐私保证。SDK/本机联验与商业客户端真实自主规划是不同结论；当前状态查任务清单。
