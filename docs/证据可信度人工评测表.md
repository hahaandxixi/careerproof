## 汇总规则

- 引用编号合法率单独从运行 JSON 读取；必须人工比较原句与对应原文。
- 结论支持率 = 支持条数 /（支持 + 部分支持 + 不支持），同时列出无法判断数、无输出样本数和评审覆盖率。该值只代表已判断部分。
- 人工过度推断率 = 标记过度的结论数 / 已完成过度判断的结论数；未评的不能当作不过度。
- 关键难例只要存在未处理的能力认证、未执行却声称通过、空实现却声称功能完成，就阻止发布；改动后保存新输出并复评。
- 引用合法但解释不支持：保存失败原句、引用、人工理由及修复后的新一轮结果，不能只留最终通过版本。
