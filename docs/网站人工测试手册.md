# CareerProof 网站人工测试手册

适用对象：第一次接触网站的老师、同学和测试人员。无需读代码。覆盖当前已开放的网站功能和人工专项入口。先做学生主流程，再做企业流程，最后按功能清单逐项补测。使用合成样例，不上传真实简历或账号凭据。没有环境、授权或预算的项记“未测”，不能据此宣称全部功能已通过。

## 先准备好（由项目负责人完成）

请负责人提供：一台已安装项目的电脑、已启动的 Docker Desktop、可正常打开的网站、学生和企业演示账号，以及本轮允许的 AI 调用次数。**测试人员不需要配置 API Key。**

本机网站地址：`http://127.0.0.1:3000/`。这只能在运行项目的电脑上打开，不能直接当作其他电脑的访问地址。

尚未启动时，在项目文件夹双击 `Start-Demo.cmd`，等待显示启动成功。初次安装请负责人按 [完整操作流程](完整操作流程.md) 配好环境。若已能打开网站，不要再重复启动。出现启动失败或已有运行记录时，把错误交给负责人，不删除文件、不重置数据库。

演示账号保存在本机 `backend/.tmp/demo-credentials.json`：`studentEmail` 是学生邮箱、`enterpriseEmail` 是企业邮箱、`password` 是演示密码。请负责人私下提供，不把这个文件截图、分享或提交。修改文件并不会修改已有账号密码。

打开“演示指南”（地址后加 `/demo`），先选一张职业卡片，下载该编号的简历、项目和测试步骤，放在桌面的 `CareerProof测试材料`。ZIP **不用解压**。CP01 是后端，CP02 前端、CP03 测试、CP04 数据分析、CP05 产品、CP06 运营、CP07 运维、CP08 数据库、CP09 数据工程；各有独立对应材料。演示初始化已导入九套时，可以直接选择现成版本；若要亲自测试上传，材料名称末尾加本轮日期，避免与预置案例重名。只做页面浏览、查看旧报告不调用模型；“生成报告”“生成 AI 职业规划”“从描述生成 AI 草稿”“视觉观察”会产生模型调用，先按负责人给的次数测试，失败也不要连续重试。

## 学生主流程：按顺序点一遍

| 步骤 | 点哪里、填什么 | 看到什么才算通过 |
| --- | --- | --- |
| 1 登录 | 打开网站，进入登录页，用学生演示账号登录。 | 导航出现“我的材料”“职业推荐”“我的匹配报告”和学生名字。 |
| 2 上传简历 | 点“我的材料”。以 CP01 为例，“简历名称”填 `CP01｜Python 后端｜测试简历-本轮日期`；文件选 `CP01-Python 后端-简历-v1.txt`；点“上传并解析简历”。其他职业按对应卡片填写。 | 出现保存提示，下方材料卡片最终“分析完成”；名称和文件名正确。 |
| 3 上传项目 | 同页“项目名称”填 `CP01｜任务管理 API｜测试项目-本轮日期`；“项目说明”填 `合成静态练习，未执行，不代表真实经历或本人贡献。`；文件选 CP01 对应项目 ZIP；保留“个人作品”；点“创建项目并开始扫描”。 | 项目卡片最终“分析完成”，编号与简历相同。不能把“已上传”当作“已解析完成”。 |
| 4 看系统读到了什么 | 在这两张卡片分别点“预览解析内容”。项目页点左侧一个源码文件。 | 简历能看到文字；项目能看到文件名、源码和行号，没有把 ZIP 当成无文字文档。回到材料页时文件仍存在。 |
| 5 找岗位 | 点“岗位发现”；关键词填 `合成演示`，点“筛选”；打开“Python 后端开发实习生（合成演示）”。 | 显示岗位描述和要求。找不到时先点“重置”再筛选；仍没有请负责人初始化演示岗位。 |
| 6 选本次版本 | 在“简历版本”下拉框选刚上传的简历。展开“选择或更换项目版本”，搜索刚填写的项目名称，展开该项目，勾选第 1 版。 | “已选项目版本”列出所选项目和版本，“本次材料”发送预览与选择一致。列表收起、搜索换词后已选项仍在；不用勾选全部历史材料。 |
| 7 确认并生成 | 阅读发送范围，勾选同意发送必要片段。首次测试不用勾选历史查询。点一次“生成我的匹配报告”。 | 跳到任务页，有进度和处理记录；最终能打开报告。此步可能收费。不要重复点、刷新后重新提交或为了高等级反复生成。 |
| 8 看报告状态 | 点“查看匹配报告”。先读顶部状态、解释和逐项证据。 | 明确区分“AI 证据初评”和“模型已降级”。后者可说明兜底链路成功，但**AI 成功项记为失败/未通过**，不要勾全部通过。 |
| 9 看引用 | 点任意引用编号（如 R1-E1），核对片段、文件名和行号；需要时打开原材料。 | 能定位真实源码；片段内容支持那一条解释。Redis 等仅自述内容不能出现虚构实现。看到代码不等于运行成功、本人编写或测试全部通过。 |
| 10 记录本人复核 | 在一条要求的复核说明写 `人工测试：仅核对展示的原文，运行与贡献未验证。`，点“采纳证据”，刷新页面。 | 状态和备注仍保留；其他要求不会一起被采纳。随后可点“恢复待复核”，避免测试记录被误当成正式审核。本人采纳不是独立专家认证。 |
| 11 找回记录 | 点“我的匹配报告”，找到刚生成的一份，重新打开。 | 材料版本和报告内容相同。不要要求固定总分：产品展示逐项证据等级，不提供录用概率或考试认证等级。 |

测试成功并不要求所有技能都高等级。样例故意有缺口；准确说明“不足以判断”也是正确结果。

## 材料多时怎么选（新版收起式选择器）

简历保持单选下拉框；项目可多选，最多 **10 个版本**，不是十个项目。所有历史版本保留，不删除、不合并旧报告。

1. 点“选择或更换项目版本”展开。
2. 搜索项目名称或文件名；点项目名称展开它的版本，勾选需要的版本。
3. 看上方“已选项目版本”：名称、版号、个人作品/第三方参考都要正确。
4. 点“移除”可取消某一项；达到十项时先移除再添加。
5. 搜索不到只是列表筛选，不会取消已经选中的版本。不需要项目时把已选项逐一移除。

“岗位分析”和“职业推荐”使用同样的选择方式。职业推荐不再自动勾选最近的项目；请主动选择与简历编号对应的作品。未解析或解析失败的版本不能选择。第三方参考可用于学习线索，不计个人实践等级。

职业推荐页只在主动生成后显示本次结果，默认展开重点岗位；其他规则候选可按需展开。更换材料会收起旧展示，不会自动再调用模型。查看历史时主动点击“查看上次保存的规划”，确认有“历史结果”标记及保存版本；这不会修改当前所选材料，也不会收费。

## 企业流程：确认后才发布

先退出学生账号，再用企业演示账号登录。只管理本次新建的合成测试岗位，不改其他人的岗位。

1. 进入“我的岗位”，点发布岗位入口。选择已有演示企业；没有企业时请负责人初始化，或创建名称为 `人工测试企业-日期` 的合成企业。
2. 岗位名称填 `人工测试后端实习生-日期`，方向选软件开发，城市填深圳，工作类型选实习，状态先选“保存草稿”。岗位描述可以复制：

   > 合成测试岗位，不是真实招聘。需要使用 Python 和 FastAPI 编写接口，包含输入校验与错误响应；能使用 PostgreSQL 做参数化查询。pytest 接口测试是加分项。请提供相应源码与可核对材料，不要求证明生产运行经历。

3. 允许本轮模型调用时，阅读并勾选岗位描述发送授权，点一次“从描述生成 AI 草稿”。未授权时按钮不能执行生成。
4. 草稿出来后，逐条点“定位原文”，检查要求来自刚填的描述，必要/加分、权重是否合理。不合理的取消勾选，不能直接全选当作通过。
5. 点“确认选中要求并填入表单”。检查要求表单，必要时修改文字或权重。草稿生成和确认都不应该自动发布岗位。
6. 点“保存岗位”，确认在“我的岗位”能看到草稿；刷新后仍可编辑。再编辑这份测试岗位，把状态改为“公开发布”并保存。
7. 学生账号应能在岗位发现搜到它；关闭该测试岗位后应不能再发起新的分析。已有报告仍保留。已有分析的岗位要求可能已锁定，系统拒绝修改时不要强行改数据库。

企业 AI 生成失败时，记下错误，不连续重试；可以手填要求验证保存流程，但不能将手填结果记成 AI 拆解通过。企业目前没有候选人私有报告入口，也不提供投递、面试邀请或学生自动排序。

| 功能 | 怎么测 | 正确边界 |
| --- | --- | --- |
| 职业规划 | 学生点“职业推荐”，选择合成材料，核对已选清单，授权后点“生成 AI 职业规划”。 | 显示候选理由、真实引用、缺口和可提交任务；故障保留候选并说明降级。推荐不是录用保证。此步会调用模型。 |
| 历史对比 | 打开已有同岗位两份报告，在较新报告点“与上一份报告对比”。 | 新增/不再展示的证据能定位；没有同岗位更早报告时明确提示。只查看不收费，不为了制造等级上涨反复生成。 |
| 版本保留 | 材料页在某个测试项目旁点“上传新版本”，上传改过的合成 ZIP；等解析完成。 | 旧版本和旧报告保留；新版本不会悄悄替换旧报告依据。重新分析另算一次调用。 |
| 图片/OCR | 上传写有明确合成声明的 PNG，点预览，对照原图检查 OCR。需要视觉观察时另读图片发送授权，再点观察生成按钮。 | OCR 与视觉描述分开；勾估计区域能在图上定位。图片不应直接提高源码评级；本人采纳描述不证明部署和贡献。视觉生成另收费。 |
| 390px 页面 | 在浏览器开发者工具开启响应式模式，宽度设 390；查看岗位表单、材料选择和报告。完成后关闭响应式模式。 | 文本不挤出屏幕，按钮可操作，材料列表内部可滚动；代码片段允许自身横向滚动，整页不应溢出。 |
| 隐私隔离 | 请负责人提供另一个合成学生账号及一条已保存报告地址。用第二账号打开该地址，再用企业账号尝试。 | 不显示第一学生的报告正文或材料；拒绝或提示无权限都可。不要测试真实他人的资料，不复制含令牌的地址。 |

MCP 客户端配置由负责人准备，普通测试人员按下节操作，不要求自己安装或写代码。本手册不能替代独立语义审核：若老师愿意审核，可逐条注明“结论是否被引用支持、是否过度推断、哪里还缺材料”，保留审核者、日期与理由。

## 全功能补测清单（含反向操作）

以下各项分别记录“通过/失败/未测”。同一份合成材料和已保存报告可以重复查看；不需要为每一行重新调用 AI。没有排序、删除、投递等按钮时不要自行猜测入口。

| 编号 | 功能与点击方式 | 通过条件 |
| --- | --- | --- |
| A01 | 首页：点击徽标回首页、导航跳转、页面顶部“跳到主要内容”（可用 Tab 找到）。 | 页面和导航可用，键盘焦点可见，能跳到正文。 |
| A02 | 注册：负责人提供两个未注册的合成邮箱；退出后进入 `/register`，选学生/企业，填显示名称、邮箱及自己保管的密码、确认密码。分别注册。 | 成功后角色正确，不提供管理员自助注册。只创建合成账号，不使用真实私人邮箱。 |
| A03 | 注册错误：两次密码不同、少于 8 字符、无效邮箱、已经注册的邮箱。 | 有明确提示，不创建错误角色或重复账号，不显示后台密码。 |
| A04 | 登录错误/退出：用演示邮箱配错误密码试一次，再用正确密码登录；退出后直接打开材料或报告地址。 | 错误提示清楚；退出后不展示私有内容。没有重置密码入口，不要求通过改本机文件重置。 |
| A05 | 会话恢复：正常登录后刷新、关闭再打开同一浏览器的网站。 | 有效会话能恢复；失效时提示登录。负责人可提供已过期会话环境，测试人员不用修改 Cookie。 |
| B01 | 演示指南：打开 `/demo`，下载 TXT、基础 ZIP、专项 ZIP、岗位说明及各职业样例。 | 文件能下载；九职业的名称、填写建议与边界清楚，运维/DBA 有工程 ZIP。下载不等于九职业模型验收。 |
| B02 | 简历格式：负责人提供合成 TXT、DOCX、可选中文字的 PDF、扫描 PDF/PNG，逐个上传并预览。 | 支持格式能解析，扫描件走 OCR；识别错误如实记录，不能把 OCR 结果当作无误原文。 |
| B03 | 项目格式：分别上传合成 ZIP、作品 TXT/DOCX/PDF、图片。 | 入口正确、文件列表和文字正常；不运行上传代码。图片是作品，不自动产生代码能力等级。 |
| B04 | 不支持/超限：负责人提供无敏感内容的 `.exe`、超 10MB 文档或超 30MB ZIP。 | 明确拒绝，不执行文件，不凭空生成成功卡片。普通测试人不要自行制作恶意压缩包。 |
| B05 | 材料刷新：上传完成后点“刷新列表”、刷新浏览器，退出再登录。 | 同一材料仍在，不重复创建版本。 |
| B06 | 新版本：在自己的测试项目旁点“上传新版本”，换合成 ZIP；已创建但未上传的项目用“继续上传”。 | 新版属于原项目，版本号可区分，旧版保留；未完成版本不能用于匹配。 |
| B07 | 上传中断恢复：由负责人临时断开本机后端，上传失败后恢复服务，按页面提示重新选择同一个文件重试一次。 | 提示清楚，同一次项目提交不重复创建项目。不要在真实 AI 任务执行中断开服务。 |
| B08 | 材料归属：新建合成项目时选“第三方参考”，上传公开样例（负责人确认许可）。 | 后续选择和报告显示第三方参考，不把它授予个人实践等级。 |
| B09 | 版本选择器：展开、按项目名/文件名搜索、选历史版本、搜索不存在名字、收起、移除。 | 已选项一直可见，发送预览一致；搜索不清空选择，最多十个版本，满额后可移除再添加。 |
| C01 | 岗位筛选：分别用关键词、方向、城市、工作类型，点筛选、重置，再点上一页/下一页。 | 筛选条件生效，重置清空，换条件回第一页；空结果有提示，首末页不能继续越界。 |
| C02 | 岗位详情：打开一个合成岗位，看原文、技能、权重和必要/加分；登录企业后看同一页。 | 内容一致，企业不出现学生材料分析表单。 |
| C03 | 草稿/关闭：负责人给测试草稿或关闭岗位的地址，学生打开。 | 不能创建新分析，不能用关闭岗位绕过状态限制。 |
| D01 | 分析授权：先不勾外发同意，尝试生成；勾选后按主流程生成一次。 | 未授权按钮禁用；没有面向用户的主动规则模式开关。 |
| D02 | 任务实时状态：生成后看进度、实际处理记录；分析期间刷新一次，完成后刷新一次。 | 找回同一任务，不因刷新新增模型任务；完成状态固定，不伪造模型思考过程。 |
| D03 | 失败任务重试：使用负责人准备的失败合成任务，读错误后点“重试此任务”一次。 | 复用原材料版本；文件错误须另上传修正版，不连续重试耗费 API。 |
| D04 | 报告页：查看当前材料版本、预览、逐项判据、等级说明、源码联合覆盖、补证计划和实际任务记录。 | 版本能对应，缺口/建议能回到要求；源码完整不自动证明代码成功执行；历史无覆盖字段时显示未知。 |
| D05 | 引用与链接：分别点 AI 引用、补证建议引用、覆盖信息引用，展开“来源证据”“证据定位信息”；复制带 `#citation-...` 的合成报告地址，刷新打开。 | 引用对应当前文件/行号，深链接能定位和展开；旧历史引用不混进当前引用白名单。 |
| D06 | 本人复核：同一条要求依次采纳、驳回、标记已修正、恢复待复核，每次填写不同合成备注并刷新。 | 状态/备注对应本次操作；驳回不继续推荐被驳回的依据；标记已修正不等于模型重新分析。最后恢复待复核。 |
| D07 | 报告列表：我的匹配报告→打开最新报告→返回；数据够多时测试分页。 | 列表仅自己的报告，第一页上一页禁用，无更多时清楚提示。 |
| D08 | 历史对比：同岗位已有两份报告，对比、打开基准、点击新增/不再展示证据；另开没有历史的岗位报告。 | 变化可定位，无历史时提示；变化标签不声称提升因果或能力认证，其他岗位历史不被自动引用。 |
| E01 | 职业规划：选择材料与授权生成一次，查看候选、跨方向比较、建议任务步骤和验收产物，展开依据/岗位原文。 | 引用真实，不把仅依赖或空函数当作完成；模型失效候选保留、有限矛盾诊断可读（需负责人准备触发样例）。 |
| E02 | 推荐转报告：在候选卡片点“查看岗位并生成完整 AI 报告”，先不提交。 | 跳转岗位详情，选择继承规划用的准确材料版本，不悄悄改成最新版本。 |
| E03 | 规划变化：负责人提供该账号已有两次规划，点“查看上次保存的规划”，展开“查看这些岗位与上次规划的变化”；需新生成时另允许一次调用。 | 改变能对应保存材料/当前引用，不保证提级或录用。刷新后再主动读取保存的规划，历史不冒充本次结果。 |
| E04 | 本次结果：进入职业推荐，选择材料生成一次，改选另一个版本；再读取上次规划，收起历史结果，展开/收起其他候选。 | 首次进入无旧结果；改选后旧展示清空且不自动生成；历史有明确标记且当前选择不变；展开不重新调用模型，原引用与转岗位材料不变。 |
| F01 | 企业组织：新合成企业账号进入发布岗位，创建自己的测试组织，刷新。 | 组织保存并可选，不看到其他企业的组织。组织未认证不显示已认证。 |
| F02 | 企业手填：新增要求、修改技能/权重/必要性、删除多余要求、保存草稿，再编辑。 | 表单与保存结果一致；必填不全时阻止保存。 |
| F03 | AI 拆解：20–6000 字合成描述、未勾授权、勾授权生成、逐条选择/取消、定位、确认。 | 未授权不能生成；要求有对应原文，确认后才填入，生成本身不发布。失败不伪造 AI 草稿。 |
| F04 | 草稿失配：生成 AI 草稿后修改岗位描述，尝试采纳旧草稿。 | 提示描述已修改、禁止采纳失配草稿；要重新生成需另计调用，可放弃 AI 草稿用人工要求。 |
| F05 | 企业发布/关闭：我的岗位的筛选和分页、编辑、发布岗位、关闭岗位、重新发布。 | 状态持久保存，学生发现列表相应改变；只操作本轮测试岗位。已分析岗位的要求锁定符合提示。 |
| G01 | 图片授权/OCR：图片预览，未勾图片外发授权尝试生成。 | 能看到原图/OCR；独立图片授权未勾不能调用，文字授权不能替代它。 |
| G02 | 视觉生成与复用：允许一次观察生成，刷新读取已有结果，再按负责人许可验证同来源复用。 | 可见元素、待核验内容、Tokens 和模型来源清楚；已保存结果可恢复；复用不隐式多次消费。 |
| G03 | 图片复核：定位估计区域、采纳/驳回描述、填写备注、刷新、恢复待核对。 | 区域可切换，描述复核持久化，图片不产生源码实践等级，恢复后不留正式人工通过记录。 |
| G04 | 无效图片来源：负责人在隔离合成环境准备已丢失/替换原图的观察，打开预览、尝试采纳。 | 当前观察不可用、不能继续采纳旧描述；不修改正常演示数据或原始历史报告。 |
| H01–H04 | MCP 授权、读三个工具、撤销、过期。 | 按下节执行；不把“生成授权”当作客户端已接通。 |
| I01 | AI 故障/额度：负责人在隔离环境准备网络故障、用量上限、非法输出三个场景，各生成一次。 | 兜底报告仍可读且有失败类别/用量记录，不伪装 AI 成功；不在测试人电脑发送真实凭据，不为通过取消校验。 |
| I02 | 权限：第二合成学生/企业打开第一学生的材料、任务、报告、规划及对比地址；另一企业打开测试企业的编辑页。 | 私有正文不可见，不能修改。负责人负责提供纯合成目标，测试者不得枚举未知 ID。 |
| I03 | 移动端/键盘：390px 测首页、材料、岗位表单、推荐、任务、报告、企业表单；Tab/Enter/Space 操作主要按钮。 | 不溢出，输入框可用，关键操作能完成；鼠标与键盘结果分别记录。 |
| I04 | 演示等级与边界：在 `/demo` 查看联合覆盖演示、九方向材料说明，在报告查看“证据等级如何划分”。 | 明确当前等级是材料支持程度，无考试证书背书、能力认证或总分承诺。 |

特殊负例、超限材料、故障模拟及第二身份由负责人预先准备，测试人员只按入口操作。没有这些条件记“未测”，不要冒险关闭用户数据库或污染其他测试者的资料。

## MCP 人工专项：有人带着也能完成

MCP 是让你选择的客户端只读查询选定报告，不是另一种网站聊天功能。请负责人按 [受控 MCP 使用与验收](受控MCP使用与验收-20260926.md) 先配好本机可信客户端；工具调用若由模型自主规划可能产生客户端模型费用。测试只用合成报告。

1. **H01 授权**：学生打开自己的合成报告，展开“外部工具只读访问（可选）”。不勾敏感信息确认时“生成十分钟只读授权”应禁用。勾确认，按需要勾“同时授权上一份同岗位报告”，生成一次。没有上一份报告时应提示，不扩大到其他岗位。
2. **H02 只读查询**：请负责人把临时凭证放到本机客户端，勿发聊天或截图。让客户端分别检索本报告证据、读取摘要；已同时授权两份报告时再做比较。三个工具为 `search_evidence`、`get_report_summary`、`compare_reports`。返回内容应只来自选定报告，脱敏/截断标记与原始定位明确；不能上传、修改或复核材料。让负责人用一条未授权的合成报告 ID 验证拒绝，不能试探真实报告。
3. **H03 撤销**：在离开或刷新授权页面前点“立即撤销”，看到撤销提示后让同一个客户端再读取，应失败。此前已读到的内容不会从客户端自动删除，不能将撤销描述成召回旧数据。
4. **H04 过期**：另发一份合成短期授权，保持页面开着，不需要等待中反复调用；到页面显示的有效期后让客户端查询，应拒绝。最多 40 次调用的边界可由负责人既有专项记录核对；普通测试不为测限额制造 41 次模型问答。

刷新只会隐藏网页里的临时凭证，不等于撤销；所以测试完必须先撤销再离开。未配客户端只能记“网页授权/撤销通过、客户端未测”。输出截图必须遮住临时凭证；商业客户端界面、回答是否受证据支持另写结果。

## 哪些功能目前没有（不要误报“找不到”）

目前未开放：学生投递/共享授权、企业候选人私有报告/排名、在线聊天/面试、账号自助重置密码、独立专家认证、高等级自动授予、文件删除管理和管理员运营后台。旧的候选人/匹配演示地址不作为新增业务入口。公网部署、录制视频、PDF、团队资料是参赛交付，不是普通用户网站测试按钮；由负责人另行验收。

## 遇到问题怎么处理

| 现象 | 先做什么 |
| --- | --- |
| 网站打不开 | 确认运行项目的是这台电脑、地址正确、负责人已启动项目。Docker 启动并不会自动启动前后端。服务恢复后刷新原错误页。 |
| 点击没反应 | 等一次加载完成；仍无反应时记录按钮名，尝试 Tab 聚焦后按 Enter（复选框按空格）。键盘成功只能记录为键盘通过，鼠标问题仍记下。不要同时重复提交。 |
| 文件不受支持/无可分析文字 | 先用演示 TXT/ZIP 排除文件因素。扫描 PDF/图片核对 OCR；项目 ZIP 与简历上传入口别用反。不要把所有失败都归为 AI 失败。 |
| 任务失败 | 记录任务页地址和错误。如果文件问题，上传修正的新版本；“重试此任务”复用原版本，不能修复文件内容。 |
| 模型已降级/限额/超时 | 报告可继续看，记“兜底通过，AI 未通过”。不要立即多次重新生成；交负责人查模型、配置或预算。 |
| 引用不支持解释 | 记录要求、引用号、片段及问题句，驳回或恢复待复核。不为拿高等级改写测试预期。 |
| 登录失败 | 核对角色账号及原密码，请负责人处理。不要改本机凭据文件试图重置账号。 |

截图不要包含密码、Key、完整敏感简历或授权令牌。异常报告提供：哪一步、哪个按钮、页面地址、预期、实际结果和脱敏截图。
