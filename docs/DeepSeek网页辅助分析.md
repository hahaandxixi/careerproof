# DeepSeek 网页辅助分析

本功能用于在没有可用模型 API 额度时，人工借用 DeepSeek 官方网页完成一次证据分析。项目不会读取浏览器 Cookie、用户令牌或接管 DeepSeek 账号，也不会自动向网页发送材料。

## 使用步骤

1. 在学生账号的匹配报告中打开“免费 DeepSeek 网页辅助分析”。
2. 点击“生成脱敏提示词”，阅读数据提示并检查提示词中的每段项目证据。
3. 删除代码中仍可能存在的姓名、地址、密钥或其他不希望交给第三方的内容。
4. 复制提示词，点击“打开 DeepSeek 官方网页”，在新对话中手动发送。
5. 复制 DeepSeek 返回的完整 JSON，粘贴回报告页并点击“校验并写入报告”。
6. 逐项点击引用核对原文，再进行人工复核。

## 本地校验

导入并不直接信任网页回答。后端会检查：

- 要求编号必须与当前报告完全一致；
- 引用编号只能来自对应要求的已保存证据；
- 有证据的要求不得省略引用，无证据的要求不得伪造引用；
- 评级判据必须完整，等级不能超过规则计算出的证据上限；
- 不得把静态代码说成运行成功、本人贡献或能力证明；
- 提示词的上下文指纹必须仍与当前报告一致。

任何一项失败，整次导入都会被拒绝，原规则报告保持不变。

## 数据与稳定性边界

提示词不会主动加入账号身份和简历自述，但会包含岗位要求以及每项最多三段项目证据原文。代码本身可能含个人信息或凭据，因此发送前必须人工检查。发送后的内容由 DeepSeek 按其隐私政策处理。

网页辅助模式依赖人工复制粘贴，不是官方 API，也不保证网页长期免费或始终可用。它适合比赛演示、少量测试和 API 故障时的人工备选。自动批量分析仍应使用受支持的模型 API，或部署在本机且许可证允许的开源模型。

本项目没有集成读取 `userToken`、Cookie、验证码处理或 DeepSeek 私有网页接口。调研过的 Chat2API、DS2API、FreeDeepseekAPI 等项目提供了会话隔离、队列、协议归一化和失败恢复方面的参考，但都依赖非官方网页协议，不能作为本项目的稳定生产依赖。
