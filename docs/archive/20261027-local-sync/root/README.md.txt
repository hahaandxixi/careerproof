# 职证 CareerProof

CareerProof 面向准备实习/校招、拥有本人简历与项目材料的学生，以及定义岗位、核对学生授权材料的企业人员。首个完整场景聚焦软件开发岗位。学生上传简历和项目，核对带来源引用的岗位分析、职业建议与补证任务；企业从岗位原文生成待确认要求，确认后发布。

## 当前实现与边界

Next.js / TypeScript 前端、FastAPI / Python 后端、PostgreSQL、本地文件存储。所有产品外部生成统一使用 DeepSeek 官方 API，文字与截图共用本地配置的 Key；不使用网页转接。API Key 不进入前端或仓库。

规则先检索候选证据并确定引用范围与评级上限，DeepSeek 在边界内解释证据、初评和规划补证。最多两轮受控规划可访问当前冻结材料与本人历史上下文；历史判断不能替代当前证据。外部AI需要单独同意；未同意时匹配/补证保留本地规则报告，不外发材料。已授权的生成仍经过引用和表达校验，故障、无证据或限额会保留降级结果。

截图观察和本地 OCR 分开记录。截图不能证明本人贡献、真实部署或持续运行，不自动赋实践等级。学生本人采纳材料也不等于独立人工语义复核。企业发布岗位不会获得学生私有材料或报告访问权。

已实现功能与使用限制见[证据与产品能力](docs/guides/证据与产品能力.md)。历史检查仅覆盖当时源码；本包不宣称冻结候选全绿，开发进度与原始记录留在开发仓库。

## 架构

- **前端** `jianli/`：Next.js 15 App Router + React 19 + TypeScript（strict）+ Tailwind。页面只做展示与交互，产品判断一律来自后端返回的结构化结果。
- **接口层** `backend/app/api/v1/`：FastAPI 路由与请求校验，统一 `ApiResponse` 封装与分页契约。
- **业务层** `backend/app/services/`：匹配、投递、补证、通知、报告等业务规则；异步分析任务用数据库租约（CAS + `run_token`）保证同一任务只有一个执行者，进度经 SSE 推送。
- **数据层** `backend/app/repositories/`：SQLAlchemy 2.0 异步仓储；PostgreSQL 17 + pgvector 存放证据向量，结构变更走 Alembic 迁移。
- **Agent 层** `backend/app/agents/`：证据工作流、受控模型调用（`provider`）、统一请求预算（`input_budget`）、缺口文案守卫（`evidence_scope`）。
- **工具层** `backend/app/tools/`：规则匹配、代码分析、静态与混合检索、规则叙述生成。
- **离线验证** `backend/evals/`：证据复核、预算对账、源码等价、源码包构建等只读校验脚本，可脱离网站单独运行。

数据流：材料上传 → 解析与切片 → 规则检索候选证据并确定引用范围与评级上限 →（可选，需单独同意）DeepSeek 在边界内解释与初评 → 引用与表达校验 → 保存报告 → 学生自主决定是否投递 → 企业只看到明确授权的固定快照。

## 本地启动

1. 双击桌面的 **Docker Desktop**，等待引擎就绪。
2. 在项目根目录（源码ZIP的解压目录，包含启动文件）双击 **`Start-Local.cmd`**，等待提示ready。
3. 浏览器打开 **[http://127.0.0.1:3000](http://127.0.0.1:3000)**；用完双击 **`Stop-Local.cmd`**。账号、材料和投递数据保留。

**首次启动前**需先按[使用与启动指南](docs/guides/使用与启动.md)准备 `backend/.env`（至少 `AI_PROVIDER=deepseek`、`AI_EXTERNAL_ENABLED=true` 与 `DEEPSEEK_API_KEY`）。缺这些时启动脚本会**直接报错并停止**，不静默降级——规则兜底是运行期行为，不是可选的启动模式。启动、登录、导入合成材料本身不调用模型。

新机器安装、账号查找、学生五步体验、企业查看及故障处理，按同一份[使用与启动指南](docs/guides/使用与启动.md)操作。已有账号和数据时使用普通启动；首次准备演示账号、合成岗位及材料才运行`Start-Demo.cmd`。

**找不到账号？** 自己注册的账号使用自行设置的密码；演示账号在本机运行 `Start-Demo.cmd` 后生成的本机 `backend/.tmp/demo-credentials.json`查找。3001是独立开发验收环境，账号和记录不与3000互通。不要修改凭据JSON或重新播种来重置密码。
