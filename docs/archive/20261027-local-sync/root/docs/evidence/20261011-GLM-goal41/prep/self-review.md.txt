## 自审中发现并已修复的缺陷（全部在准备阶段发现，未进入实跑）

1. **Chrome 构造器作用域缺陷**：构造器最初引用 main() 局部的 `RUN_STAMP`（ReferenceError 必现）。改为构造参数 `stamp` 必填校验。
2. **PowerShell 参数传递错误**：`powershell -Command <script> arg1 arg2` 的 arg 不会绑定 `$args`（会被拼接成新语句）。改为把 pid/cmdShow（本 run 自产的数字）直接内嵌进命令串。修正后用自有 WinForms 探针窗口完成真实 MINIMIZED→RESTORED→MINIMIZED 往返验证（静态测试 #10，10/10 过）。
3. **leakScan 的 localStorage/sessionStorage 假检查**：`JSON.stringify(storage)` 恒为 `"{}"`，marker 若入库也查不出。改为逐 key 枚举真实转储后扫描。
4. **坏参数闭合演示**：5 组非法参数全部 exit=3 且不产生任何文件（证据 prep-args-closure.raw.out）。
5. **隐藏态后续步骤风险**：任一步 hide/restore 失败后窗口可能停留在隐藏态，后续 fillText 会对着最小化窗口发鼠标事件。新增 `ensureVisible` 守卫：每步开始确认 `document.visibilityState === "visible"`，否则先真实恢复；恢复失败抛 `PageAbortError` 诚实中止剩余页面步骤（记 blocked），`finally` 仍关浏览器，终态只读比对在无 after-seed 基线时如实跳过。
6. **fixture 快照哈希复刻不可行（实测确认，非假设）**：存储文本含 Python 浮点 `overallScore: 55.0`，JS Number 解析为 55，seeder 的 `normalized_snapshot_hash` 无法在 JS 字节级复刻（0/3 一致，见 prep-fixture-hash.raw.out）。处置：runner 中 fixture 交叉核对降级为**信息性记录**（不作为门禁）；硬不变量改为 before/after 全量原始文本哈希全等（`appsRawSha256`/`draftRawSha256` + 逐行 `rowSha256`），任何变化必然现形。
7. **BOM 防御**：凭证文件实测无 BOM，仍加 `replace(/^\uFEFF/, "")` 防止 Codex 侧重生成文件时引入。
8. **测试断言修正**：`assert.equal` → `assert.deepEqual`（对象比较）。
