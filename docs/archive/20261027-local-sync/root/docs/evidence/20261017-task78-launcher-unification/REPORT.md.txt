## 五、环境事实（重要，未修）

当前工作区**预检不通过**，`Start-Local.cmd` 会停在依赖校验并给出可操作原因：

```
D:\jbcode\web ai\jianli\jianli                                  -> Stale next runtime
D:\jbcode\web ai\jianli\backend\.tmp\dep-frontend-20261010      -> Stale frontend lock
D:\jbcode\web ai\jianli\backend\.tmp\dep-frontend-20261017      -> Stale frontend source copy: src/app/globals.css, ...
Run npm ci in jianli/ or select an up-to-date -FrontendStage.
```

根因（只读核对，未修）：`jianli/node_modules` 是 **pnpm 的 `.pnpm` 存储布局**，而
`scripts/dependencies/verify-frontend-runtime.mjs` 按 npm 扁平路径取 `lock.packages['node_modules/next']`，
取不到即为 `undefined`；同时已装 `next 15.5.25` 与锁内 `15.5.27` 不一致。按卡**不安装、不降级、不改锁**，
所以该项留给 Codex：在 `jianli/` 重新 `npm ci`（或产出一个与当前源码/锁一致的新 `dep-frontend-*` stage）。

后端侧本工作区可验证通过：`backend/.venv-dependency23/Scripts/python.exe`，PyJWT **2.15.0** 与声明一致；
`backend/.venv` 仍为 2.10.1，脚本会自动跳过它（不再把该环境当生产漂移）。
