## 3. A组：离线 Agent 源码哈希

### 现象和影响

原远端 SQLite 整体：**13失败、1564通过、94跳过，退出码1**。失败集中在 `test_agent_evidence_smoke.py` 和 `test_agent_smoke_hard_stop.py`。

主要报错为 `Agent reviewed source changed`。预算、缺失usage、回执写入失败、HTTP400/401硬停止等用例因此未进入各自要验证的阶段，不能把这批失败解释为这些生产机制全部失效。

完整13个失败nodeid与错误摘要：[原始用例清单](integration/original-unit-failures.txt)。完整原始日志保留在本机 `backend/.tmp/ci-39877034041-unit.raw.log`。

### 根因

八份受审查源码中，以下两份缺少明确的LF检出属性：

- `backend/app/agents/evidence_policy.md`
- `backend/app/agents/input_budget.py`

当前离线夹具记录的是两份文件的CRLF字节哈希，而Git blob及Linux检出为LF。逐文件比较确认：仅转换换行即可对应；其余六份已匹配。不能将其理解成供应商API、真实模型输出或业务数据库故障。

### 修复和结果

- 在 `.gitattributes` 为两个路径明确 `text eol=lf`。
- 只更新 `fixtures/current-20261022/agent-offline-input.json` 的两个源码哈希，使其对应已审查的Git内容。
- 生产字节校验保持原样；历史授权包、真实输出和claim没有改写。
- 新增两项真实内容突变回归：合法内容通过，增加内容后仍拒绝。
- 定向红例：13失败/12通过；修复后27通过、0失败、0跳过，退出码0。
- `core.autocrlf=true/false` 两种检出设置下，八份文件共16次哈希比较全部匹配。实际Linux执行由最终成功CI补齐。

证据：[A组说明](hash/README.md)、[字节核对](hash/byte-baseline.json)、[检出矩阵](hash/checkout-matrix.json)、[修复前完整回溯](hash/red-final.raw.out)、[修复后JUnit](hash/green.xml)。

### `KeyError: guard` 的准确状态

来源校验在guard建立之前已经失败，测试的finally又访问未创建的guard，产生第二个错误，遮住预期的“最终日志持久化失败”提示。A1修复后，该用例实际进入预期阶段并通过。

**本轮没有单独重构这段测试兜底。** 如果未来再次在初始化前失败，其诊断仍可能不够清楚；可作为低优先级测试可维护性事项，不能写成已独立修复，也不能当作当前仍在失败的业务功能。

## 4. B组：hard-stop 进程身份

### 现象和影响

原Linux CI的8个场景全部失败于：

```python
assert worker.parent_pid == child.pid
```

例如首例期望父PID10285，实际10137。失败发生在实际kill与恢复之前，旧结果不能证明Linux停止恢复已经通过。

8例为 verification、matching 两条链，分别覆盖：`send_intent_committed`、`response_observed`、`receipt_committed`、`ledger_committed`。完整nodeid见[原失败清单](integration/original-pg-failures.txt)。

### 根因及修复

- **直接启动**：worker PID就是Popen PID，它的父进程应当是本次pytest进程。
- **启动器模式**：实际worker是Popen启动器的子进程，它的父PID才应当等于Popen PID。

新增小型身份核对函数区分这两种关系，并拒绝无关/兄弟进程和已经退出的启动器。原有nonce、任务、schema、创建时间、HTTP计数、账本、实际kill/wait、锁释放及幂等恢复断言全部保留。没有跳过Linux，没有新增xfail或提前返回。

### 实际验证

- 身份回归红例：2失败/6通过。
- Windows身份、既有worker和资源回归：35通过，退出码0。
- Windows实际强停与数据库恢复：8通过、零失败/跳过。
- 最终Linux CI实际强停与恢复：8通过、零失败/跳过。
- 两个平台严格PG集合及JUnit门禁通过；不是只修正启动断言后就声称恢复成功。

证据：[B组说明及命令](process/README.md)、[身份红例](process/identity-red.raw.out)、[Windows强停JUnit](process/windows-hardstop.xml)、[最终集成强停日志](integration/pg-hardstop.log)。
