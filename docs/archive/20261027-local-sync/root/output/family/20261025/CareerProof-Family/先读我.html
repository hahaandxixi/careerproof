这个网站把岗位要求与简历、项目文件逐项对应，让人能点开来源核对，也能根据缺口补充新版材料。请按真实感受试，不用追求高分。

这是本机试用包，不是免安装软件。适用于 Windows 10/11、Intel/AMD 64 位电脑，不用另装 Python、Node.js 或数据库；先安装并打开 Docker Desktop。本包已带运行组件，Docker 安装完成后可离线试用本文的 TXT/ZIP 规则报告路线。建议预留至少 8 GB 可用磁盘空间。包内没有真实个人资料或 API 密钥。

一、第一次打开

  1. 将整个 ZIP 解压到电脑上的普通文件夹，例如 C:\CareerProof-Trial。不要直接在压缩包里运行，也不要只取出一个启动文件。
  2. 如果未安装 Docker Desktop，打开官方 Windows 安装说明，按电脑类型下载。按安装程序要求完成 WSL 2／虚拟化配置及必要重启。保持默认 Linux containers 模式——电脑仍然是 Windows。若安装这一步卡住，请让家人协助，不必自行修改系统设置。
  3. 打开 Docker Desktop，等它显示 Engine running。
  4. 双击 01-Start.cmd，等待显示“启动完成”。首次会导入随包组件并初始化本机数据，通常需要几分钟，请不要关闭。成功后会自动打开网站和本机账号说明。
  5. 用账号说明中的学生账号登录。以后仍双击 01-Start.cmd；忘记账号可双击 03-Accounts.cmd。

网址：http://127.0.0.1:3150。这个地址只能在启动试用包的电脑上使用，不能把它发给别人当作在线网址。

二、先体验这一条路线

  1. 登录学生账号，打开“我的材料”。从包内试用材料文件夹选择 event-api-resume.txt 作为简历、event-api-project.zip 作为项目；分别上传，项目 ZIP 不用解压。名称可填“活动报名简历”和“活动报名项目”。等待两项处理完成。
  2. 打开“发现岗位”，选择Python 后端开发实习生。明确选择刚上传的简历版本和项目版本。
  3. 不勾选外部 AI 同意，点击生成匹配报告，等实际任务结束。本包禁用外部模型，不会产生模型调用费；这一步是本地规则分析，不能当作真实大模型质量体验。
  4. 打开报告，选一条岗位要求，再打开引用：是否能找到文件、行号和原文？报告说的依据与你看到的一致吗？规则未覆盖不代表你没有能力。
  5. 看一条补证建议。如果需要练习完整补证，可创建补证任务，给原项目上传真正补充过的新版，返回任务明确保存版本选择，再生成新报告。原报告与已投递快照不会自动替换。暂不改材料也没关系，反馈“是否知道下一步做什么”即可。

想看企业端时，先由学生在报告页阅读授权范围、明确确认站内投递，再退出并用企业账号查看。仅限这些虚构岗位和合成材料；不会发给 BOSS 或真实公司。不需要为了完成试用而发送企业回复。

三、用完、下次继续和反馈

  • 双击 02-Stop.cmd，仅停止本包服务，账号、材料和报告保留。关闭浏览器或启动窗口不会停止后台服务。
  • 保留解压目录，尤其是首次启动后生成的 .local 文件夹；不要在 Docker 中删除本包的数据卷。数据保存在本机 Docker 卷中，搬走 ZIP 不等于搬走已上传材料。
  • 把试用反馈.txt填好发回，卡住就写页面、按钮和看到的提示，可附截图。请勿转发 .local、密码或私人材料。

四、打不开时

现象处理
Docker 未就绪打开 Docker Desktop 等待完成；本包不会替你修改系统权限。
运行组件导入失败／校验失败确认 ZIP 传输、解压完整，磁盘空间充足。不要单独移动 images 或 source 文件夹；保留窗口和 logs 供排查。
3150 端口被占用若本包已启动，直接打开网址；否则把提示截图给家人，不要随意结束其他程序。
浏览器登录后提示没有权限学生与企业账号用途不同，请按本包账号文件登录，不要套用他人电脑的旧任务链接。
报告有缺口／规则不覆盖可能是材料本来缺失或规则范围有限，不是必须拿满分。请点引用核对，再反馈是否说清楚。
