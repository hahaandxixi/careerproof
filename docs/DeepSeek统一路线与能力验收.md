# DeepSeek 统一路线与能力验收

更新日期：2026-09-26。用户已决定后续全面使用DeepSeek；本文是当前路线，早期千问/智谱试验仅作为历史保留。目标是增强证据驱动的职业成长与企业岗位定义，不增加供应商数量，不以预计比赛分数替代验收。

## 配置与边界

- 学生证据报告、历史上下文规划、职业规划、企业岗位拆解、截图理解都通过同一DeepSeek官方API、Key和`deepseek-flash`。产品不会选择其他供应商，旧诊断入口停用。
- 本地OCR、词法/哈希/ONNX检索、引用逐字校验与被动规则降级继续运行。它们不调用其他外部生成模型；无需为了供应商统一替换已有本地能力或部署新的GPU服务。
- 原图外发需要本人单独授权，图片不会自动像素脱敏。文字授权与图片授权不互相替代。
- 所有自动测试隔离真实API；真实调用使用合成数据且显式执行。视觉单次请求最多1000输出Tokens，不自动重试；成功结果按来源哈希与提示版本复用。
- 规则负责证据边界、候选预筛和异常兜底；不增加可主动选择的用户规则模式。无证据、未授权或预算限制时不凭空生成能力结论。

## 接下来按验收推进

1. **补齐视觉组合验收**：当前浏览器键盘与规则报告附件已通过；再验鼠标和完整AI文字报告组合。保证未授权不外发、模型失败保留原图与OCR、图片不产生源码等级。
2. **强化证据与解释一致性**：检查空实现、仅依赖、矛盾材料和源码脱敏误伤；保留失败原始输出，不把词法校验等同于语义支持。
3. **完善成长助手**：当前材料决定本次结论，历史仅供参考；材料撤回、岗位要求变化和错误旧报告不能直接沿用评级。学生补证任务与企业确认后的要求都能定位原材料。
4. **扩大检索评测**：先建立合成同义、跨文件、空实现、仅依赖、无关材料难例，冻结词法/混合/语义结果；项目外人工再独立标注。无需增加付费模型调用。
5. **验证MCP与漂移**：沿用本人范围、短期授权与独立审计；模型漂移检查保持手动、显式允许付费，不自动覆盖基线。商业客户端联验需具体客户端支持，不编造结果。

正式视频、团队名单、评审访问与最终PDF另列提交准备，按用户安排后续完成，不抢占本轮核心质量工作。
