# Codex独立保留反例（运行前期望）

2026-10-10，ZCode25已在界面完成并交棒后，Codex独立编写。仅合成离线输入，不创建provider/联网/DB；这些标签是AI审查者判断，不是人类评分。

1. 相同岗位要求ID、同名源码、同一局部引用ID，但源码返回值改变：生产引用契约可能接受旧ID，因为它没有跨报告来源命名空间；不能将接受误算成跨版本引用正确。生产compare_views必须按内容hash/snippet输出证据新增和移除，不能判无变化。
2. 同一源码文本从portfolio变成reference：内容hash可相同，但比较必须识别来源角色变化；不能继续证明本人实践。
3. 草稿仅写“进一步完善岗位材料 / 按要求补充相关资料 / 材料符合岗位要求”：字段齐全不等于具名、可执行、可观察。契约可能接受，但不赋可操作性通过率；保留质量缺口。
4. 源片段和位置正确但检索元数据hash被篡改：离线sourceExact检查必须失败，不能只对比片段文本就报告来源完全精确。
5. 人为注入一次有效引用误拒和一次越界引用误收：黄金分母仍须保持2个正例、5个负例；不能先排除失败再算100%。应分别得到契约precision/recall=0.5、越界拒绝率0.8，并保留两项失败。
