## 已测量

- 引用契约接受/拒绝、当前检索来源的路径/角色/行范围/片段/内容哈希一致性，以及生产变化比较返回的变化类型。它们是结构与规则指标，不是引用语义正确率。
- 引用指标先累计全部黄金标签分母，再统计预测；注入两类误判的反例验证 precision/recall 会降至 0.5，而非丢弃失败项后仍报满分。
- 五个独立反例覆盖同要求同局部引用 ID 的跨版本重放、相同哈希但角色改变、空泛建议、检索哈希被篡改、错误预测的统计分母。
- `final-target.raw.out`：目标与独立反例共 15 通过、0 跳过；`ruff-final.raw.out` 通过。`final-run1.json` 与 `final-run2.json` 除生成时间完全一致，见 `repeat-check.json`；报告保存生产源码、runner 和样例哈希。

## 口径修正与实际限制

v2 将原先作者标注的建议交付物/步骤/核验覆盖率改名为 `authoredOperabilityCounts`。`operabilityCounts`、`generatedPlanOperabilityRate` 和 `semanticQualityPassRate` 保持 null；网站真实生成样本数为 0。六份草稿的作者标注齐全不能证明建议可执行。

相同要求和局部引用 ID 在材料内容变化后仍可能被引用契约接受。比较层能识别证据哈希或来源角色改变，但并不验证自然语言解释是否正确，也不能据此声称跨版本引用语义安全。原样例的旧要求集合拒绝测试仍有用，但覆盖范围窄于这个独立反例。

`cit-gap-reference-mention` 的原叙述仍带有早期评级措辞；以其已记录修正的黄金断言（裁决保持 gap、引用来自 reference）为准。未静默修改原标签或覆盖原证据。v1 原报告中的 6/6 是作者覆盖率，最终口径以本目录 v2 为准。
