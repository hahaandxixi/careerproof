## 5. 接管约束

- 遵守[协作规则](协作规则.md)，先核对Git、实际源码与运行身份，再确定本轮范围。
- 已关闭的LF检出／跨平台worker测试、分页、选证、来源显示与布局，只在新可复现回归时重开。
- 不覆盖其他执行端成果，不`git add -A`，不清理未跟踪文件或P2 stash；已提交、待集成和历史快照分开。
- 不改历史报告、投递快照、模型回执或人工答案；不为了验收放宽账号权限。
- 不自动外发材料或请求真实模型；旧授权／claim不能复用。提交、推送、公开、部署分别依当前授权。
- 不把规则、Mock、结构通过、人工语义、首次用户验收混为一个完成状态；不拼接不同源码的测试数字。
- 只读任务相关源码和证据，不默认扫描全部历史；旧待办不自动派工。
- 新验证修改本页对应字段，已完成过程追加到有日期的历史或evidence，不再向本页顶部叠加长日志。
