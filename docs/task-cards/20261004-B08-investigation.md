# B-08：模型用量与任务租约解耦的只读调查

1. 编号与目标：B-08 调查；给出可实施且幂等的已发生模型用量入账方案，不在本卡改生产代码。
2. 触发步骤：合成核验任务收到带 usage 的模型响应后，模拟 `finish_task` 因租约失效返回 `False`，再模拟任务取消或数据库短暂失败。
3. 当前表现：`application_verification.py` 只在 `finish_task` 成功的分支插入 `AiUsageLog`；已发生用量可能丢账。
4. 预期与验收：明确“已收到可信 usage”“仅发出请求但未收到 usage”“重复收尾”三种状态各自的入账与展示语义。
5. 允许读取：`backend/app/services/application_verification.py`、`task_lifecycle.py`、`app/agents/provider.py`、`AiUsageLog` 模型/迁移/相关测试；仅可新建 `docs/evidence/20261004-B08-investigation/`。
6. 禁止修改：生产代码、迁移、现有测试、Bug 清单、B-11/B-16 文件、P2 stash；不得真实调用 DeepSeek。
7. 不变量：撤回后不得保存模型结论或重新开放旧投递；用量记录不得重复；日预算要计入已知真实消耗，不把估算值伪装成账单事实。
8. 测试：只读定位现有覆盖；可在隔离合成夹具中运行现有定向用例，记录原始命令、完整脱敏输出和退出码；不修改公共业务数据。
9. 交付：一页方案，列事务边界、唯一键或幂等手段、取消/崩溃窗口、迁移兼容、故障注入测试与跨角色授权影响；标清哪些只能保守估计。
10. 停止条件：需要 schema 变更、外部 API 调用、真实数据或推送时先交方案，由 Codex 审定设计后再开实现卡。
