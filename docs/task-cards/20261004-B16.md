# B-16：企业简历下载的 blob URL 生命周期

1. 编号与目标：B-16；企业下载大文件或浏览器延迟处理时，文件完整到达浏览器下载列表。
2. 触发步骤：合成企业账号打开已查看的合成投递，下载合成大文件；对比当前 1 秒撤销行为与延迟处理场景。
3. 当前表现：`ApplicationBoard.tsx` 在 `anchor.click()` 后 1 秒撤销 blob URL；实际 0 字节或失败尚未复现，先验事实。
4. 预期与验收：下载完整、文件名正确；撤回后新请求仍被拒绝；页面卸载或重复下载不泄漏无主 URL。
5. 允许修改：`jianli/src/components/ApplicationBoard.tsx`、必要的新局部下载辅助模块及其测试、`docs/evidence/20261004-B16/` 新证据。
6. 禁止修改：后端、投递快照/授权模块、现有 Bug 清单和接力清单、B-11 文件、P2 stash。
7. 不变量：先经现有授权复查才调用浏览器交付；不声称浏览器已写入磁盘；已下载副本无法收回。
8. 测试：先记录可复现证据；再做最小回归测试，跑受影响前端测试、前端全量、类型检查、生产构建；命令与脱敏完整输出入证据包。
9. 页面：合成双端中企业下载首验，至少桌面与 390px；记录下载列表、文件大小/哈希和截图，精确恢复合成夹具；工具不可用标未验证。
10. 停止条件：无法复现时只记录证据与风险，不为消耗额度强改；真实数据、外发、Git 推送或越界修改前停止。
