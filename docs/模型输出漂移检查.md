# 手动输出漂移检查

此工具将固定难例的两份保存结果比较，分别列出引用合法性、证据上下文、评级判据/等级、明显过度结论、跳过与服务失败变化；摘要/解释/建议的措辞差异单独列出。程序差异不是结论支持率，独立人工语义复核仍待完成。

在backend目录、虚拟环境中执行离线对比，不调用模型：

```powershell
.\.venv\Scripts\python.exe -m evals.check_output_drift --baseline evals/trust-deepseek-v6-20260918-run1.json --current evals/另一份保存结果.json --output evals/drift-新的时间戳.json
```

显式允许付费时才能执行新调用：

```powershell
.\.venv\Scripts\python.exe -m evals.check_output_drift --baseline evals/trust-deepseek-v6-20260918-run1.json --live --allow-paid --max-cases 3 --output evals/drift-live-新的时间戳.json
```

默认最多3例，可显式选1–11例；使用仓库的固定合成难例，没有原始简历。每例沿用Provider的输入/输出上限和有限重试，API费用由运行者承担。本脚本不通过Web日限额服务，不能拿来规避项目限额；应单独规划评测费用，不加入日常自动化。它直接评测约束输出，并非完整生产工作流验收。

冻结基线只读并保存SHA256，禁止覆盖已有输出；实际新结果、失败与未执行案例全部保留。不自动更新基线、不自动签署人工复核。记录旧/新提示版本与供应商，具体模型和用量保存在currentRun中。

`drift-offline-self-check-20260926-v2.json`仅是同一旧文件的离线自检：11例均未发生程序差异，无新模型调用，不能证明当前模型没有漂移。新增专项测试覆盖措辞与评级区分、故障保留，以及缺少付费开关时调用前退出。`drift-offline-self-check-20260927.json`为比较规则修订入库后对同一基线重新生成的自检，仍为11例无程序差异，无新模型调用。
