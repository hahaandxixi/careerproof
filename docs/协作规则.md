# Codex、ZCode 与 DeepSeek Harness 协作规则

更新：2026-10-13，当前用户偏好优先于历史套餐记录。用户已将Trae替换为桌面DeepSeek Harness。两个客户端都是总控调度的开发执行端：ZCode使用智谱GLM，DeepSeek Harness使用DeepSeek Flash；网站自己的AI调用单独配置与计量。

| 工作 | ZCode执行 | Codex负责 |
| --- | --- | --- |
| 有界功能与简单修复 | 实现、目标/受影响测试、首次页面验收 | 拆任务、边界与集成审查 |
| 复杂授权、并发与预算 | 按已确定协议实现独立部分 | 协议设计、安全裁决、高风险独立复验 |
| AI质量评测 | 合成样例、可重复runner、原始结果和自审 | 独立保留样例、可信引用/归因审查、P2决策 |
| 文档与交接 | 新证据文件和验收草稿 | 核对证据、定稿、当前状态和本地Git提交 |

DeepSeek Harness同样承担有界实现、自动测试、首次页面验收和证据草稿；默认由一端实现、另一端独立审查，Codex签收。首项[46号隔离演示审查](task-cards/20261013-HARNESS46-release-smoke-review.md)只读业务源码、唯一写独立证据目录，待空闲时段发送。能力以实际工具与结果为准，不按厂商名称预设正确率；不把两端得出同一结论视为两个独立测试。

额度由Codex安排：优先当前有效赠额处理有价值的小修、批量测试和文档；复杂/阻塞任务可按授权提前用个人GLM-5.3。DeepSeek Flash承接独立审查与另一组有界任务。每批核对额度组、剩余量、有效期和实际用量；失败先判定原因，不重复烧额度。用户2026-10-13将智谱每周使用规划提高到90%，计入其他任务，保留10%；不自动充值/购买订阅。免费模型可按任务选择最高推理，不为消耗额度制造任务。

DeepSeek Harness遵循用户避峰要求：按用户提供的北京时间工作日09:00—12:00、14:00—18:00规则，在这些时段不发新模型任务，改用ZCode或做本地准备；节假日费率未经核实则保守按工作日时段避峰。时段与费率依据分开，不宣称官方价格已核实。不无限续跑跨入高峰的长目标，任务设停止检查点；观察到任务仍运行时先核对已产生结果，保留文件后停止继续调用。无需为避峰重发、重做已有任务。

模型费率只采用当日可取回的官方页与实际账户记录。用户贴出的DeepSeek表格属于参考资料，不能当实时账单；2026-10-12官方价格页取回超时，未确认当前费率或模型版本。缓存命中/未命中输入与输出分开计量，赠额/充值余额按服务账单核对。2026-10-13已确认运行中的 `D:\harness\DeepSeek Harness.exe`，界面显示 `DeepSeek-V41-Flash High`；这不证明请求成功或余额充足。Trae任务未发送，旧客户端信任提示无需继续处理。

两端每个新任务按“传智杯”序号递增并标明客户端，放入本项目。实际仓库为 `D:\jbcode\web ai\jianli`；客户端顶部jbcode/master不能替代嵌套仓库main/HEAD检查。任务卡明确文件所有权、数据库所有权、验收和停止条件，默认不提交/推送。

同一文件、数据库夹具、Next构建目录只允许一个写入者。可并行执行互不重叠的文件任务；Codex不能同时改ZCode正在写的文件，也不能清理其未提交成果。P2暂停stash不擅自应用或删除。

ZCode交付原始命令/完整日志、失败留档、截图、源码与夹具hash、自审和一屏终态。Codex审证据与风险文件，对授权/撤回/并发/固定快照做代表独立复验，不以模型自报完成代替验证。

用户已授权通过两个开发客户端委派本项目的任务；发送限定任务卡与所需项目源码，不发送.env、密钥、凭据、真实个人材料或无关客户端数据库。真实网站模型、真实材料外发、外部收件人、Git推送和部署须各有对应授权；开发客户端额度许可不等于网站DeepSeek外发许可。网站合成Mock与真实模型质量/费用分别标记；缺独立人工语义复核时保持未验证。

本地代码按可验证批次提交Git，只显式暂存本轮文件。用户改动、历史临时文件、密钥及真实材料不混入提交。当前接力保持短小，阶段完成或约80–100k经验上下文阈值准备新会话，不伪造精确上下文量。

Windows操作使用computer-use，先核对唯一客户端窗口、模型和目标任务，再发送；检测人工输入时刷新，不误发其他项目。首次仓库信任/API密钥等安全提示由用户手动处理，工具要求不得代点安全权限提示。Docker Desktop需要启动时按用户要求双击桌面图标，之后独立检查Engine、容器与数据库健康；不重置卷。
