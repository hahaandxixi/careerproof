## 目录职责

`guides/` 是唯一使用说明分类。`task-cards/` 只保留尚未签收或待发送任务；相关旧协议不得重跑。`templates/` 只有[任务卡](templates/任务卡模板.md)和[证据包](templates/证据包模板.md)两份通用模板。`prototypes/` 是合成设计参考，不能当正式网站功能。`evidence/` 保存有效验收证据，按任务清单里的链接按需查阅。

历史资料统一归入证据类：[历史验收汇编](evidence/历史验收汇编.md)、[历史任务协议](evidence/历史任务协议.md)、[固定人工复核样例](evidence/人工复核样例.md)。不再保留 archive 旧目录、旧供应商教程、两份过期 GOAL 或旧赛事状态可视化。历史配置与待办仅供溯源，当前目标以任务清单为准。原始失败日志、截图、来源哈希和模型结果保留，旧文件可从 Git 恢复；[整理映射与校验](evidence/文档整理-20261013.json)。

## 维护约定

优先更新现有分类指南，不再按日期新建总控、GOAL、使用手册或重复 README。状态只写任务清单，接力仅保留当前现场与下一步；长记录放证据目录。任务交棒签收后并入历史任务协议并删除单独卡，未签收卡不能按日期清掉。评测样例放证据或 backend/evals；不堆入日常使用说明。原始日志不得为整理文档而篡改。
