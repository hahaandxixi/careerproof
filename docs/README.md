## 源码包与开发记录

`guides/`保留安装、演示、架构、评测、隐私和许可说明。开发仓库的任务卡、模板和历史原始证据继续保留，不作为用户运行前提。评审ZIP只包含指定提交的文件，所需合成测试JSON随包保留；文件清单和哈希见包内 `SOURCE_MANIFEST.json`，不是完整Git仓库或验收结论。

文档不包含账号口令或API密钥。运行后生成的本机凭据文件按启动指南查找，不随源码包分发。完整Git历史与评审访问由团队通过托管仓库提供，视频与PDF另行交付。

## 在仓库中查找资料

| 目录或文件 | 用途 |
| --- | --- |
| `guides/` | 面向使用者和评审的操作说明，以本页上方导航为入口 |
| `当前接力.md`、`任务清单.md` | 最新实施状态与待办，先读顶部；下方旧日期记录用于追溯 |
| `协作规则.md`、`templates/` | 开发协作约定与任务、证据模板 |
| `task-cards/`、`evidence/` | 历史任务与原始验证资料，需结合生成版本和验收范围阅读 |
| `prototypes/` | 设计参考与原型，不能据此认定当前网站已实现或验收 |

启动所需的环境、构建和临时材料由启动指南说明。目录名称含日期、未被Git跟踪或放在临时目录中，都不能单独证明可以删除；尤其要保留仍被目录联接使用的依赖，以及报告、授权和复验所需的固定资料。
