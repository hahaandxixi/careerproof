## 源码包与开发记录

`guides/`保留安装、演示、架构、评测、隐私和许可说明。开发仓库的任务卡、模板和历史原始证据继续保留，不作为用户运行前提。评审ZIP只包含指定提交的文件，所需合成测试JSON随包保留；文件清单和哈希见包内 `SOURCE_MANIFEST.json`，不是完整Git仓库或验收结论。

文档不包含账号口令或API密钥。运行后生成的本机凭据文件按启动指南查找，不随源码包分发。完整Git历史与评审访问由团队通过托管仓库提供，视频与PDF另行交付。
