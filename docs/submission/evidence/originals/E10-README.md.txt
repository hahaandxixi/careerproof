# 上传材料本地内容核对提示

## 已实现

新解析的简历正文、项目可解析文本，经过本地短语/同句组合规则，提示疑似色情招揽、明确辱骂威胁、招聘收费/诈骗诱导和垃圾广告。参考公开招聘平台的风险分类，规则由本项目自行编写，没有复制平台词库，也不能代表其审核能力。

这是一项**上传后、解析文本上的提示**，不是上传前阻断或违规裁决。正常源码、过滤测试、反诈引用也可能命中。单独的kill、sex、DELETE或“色情”不触发；原文、索引内容、评级、分享权限和快照均不改写，不自动封禁。未命中不代表安全。仅覆盖词表可识别文本，不做图片审核或恶意代码检测。

上限200份文本、50万字符、30条位置，路径1024字符；达到限制会显示未完整覆盖。简历行号相对所标注的解析段（另列原页如有），项目行号相对原文本。持久载荷只保存类别、规则ID、路径、行号及有界计数，不保存命中原文片段。通过既有任务载荷返回，不加接口或迁移。

任务页在处理记录外明确显示提示，可展开位置，链接回材料上传修正版。旧版本、报告和投递不会因此被替换；没有假确认按钮或把无提示写成“安全认证”。
