# 评委快速体验指南 B1

CareerProof帮助学生按岗位核对作品证据、从缺口补充新版，并让企业查看明确授权的固定报告。演示人物、企业和项目均为合成数据；报告不构成能力认证或录用结论。

## 一、先选体验方式

- **已有评审专用环境**：向团队私下领取实际网址、学生与企业两套账号和场景入口清单。不要复用另一环境的账号。下文直接从第二节开始。
- **自行复现**：下载本次f6bf1ed源码快照，在全新目录解压。按包内backend/README.md“无外部AI的隔离交付复现”和jianli/README.md安装。安装准备与功能体验是两步，不要求评委具备开发环境才看懂作品。

首次准备建议Python3.12、Node22.23.1、Docker与专用PostgreSQL/pgvector。后端新建虚拟环境并安装`.[dev,mcp]`，前端执行`npm ci`；按包内依赖校验脚本核对版本。不要复用作者的.venv或node_modules。

隔离环境使用新的库名/存储，示例端口55441、8107、3107。先检查端口空闲，若被占用由准备者成套更换并重新构建前端。数据库仅绑定127.0.0.1；不使用日常compose数据库或开发数据目录。迁移前再次核对DATABASE_URL实际指向新库，禁止通过删除旧库恢复。

在独立backend/.env手工填写本机数据库配置，设置`AI_PROVIDER=mock`、`AI_EXTERNAL_ENABLED=false`、独立`STORAGE_BASE_DIR`和对应FRONTEND_ORIGINS。不要填写真实模型密钥。执行`python -m alembic upgrade head`，按后端说明启动8107；前端设置BACKEND_ORIGIN为8107，`npm run build`后以3107启动。此路线使用手动隔离入口，不与要求DeepSeek的Start-Local.cmd混用。

合成数据按后端README的seed_demo步骤准备：三个DEMO环境字段必须成套，密码仅在本机或私下保存；seed指向本轮8107的API。普通恢复不重新播种。完整校园报名案例的V1/V2材料可从仓库demo/complete-projects及对应固定材料记录核对；基础播种不会自动重建历史报告ID，准备者需按真实创建结果填写下方场景清单。

本次未再执行干净安装。已有r7干净复现属于历史版本；B1仅完成提交导出及包内检查，不用旧结果冒充当前安装通过。

## 二、学生按六步体验

1. 用本环境的学生账号登录。打开“我的材料”，确认是校园报名项目及已完成解析的版本。
2. 打开与该项目配套的岗位，核对岗位要求。在材料选择区选择明确的简历/项目版本。
3. 不勾外部AI同意，生成规则报告。等待任务完成后打开报告，先看模式和本次固定版本。
4. 选一项Python或SQL要求，展开来源。核对项目、版本、文件、行号与实际原文；代码块可独立横向滚动。
5. 从一条缺口进入补证任务。已有任务优先打开，查看基准后选择已处理的新版，明确保存选择，再主动生成新规则报告。观察来源增减，等级保持不变也属于有效结果。重复内容换版本号不算新增证据。
6. 需要分享时，在报告页阅读范围、勾选同意并确认投递。仅查看报告或创建补证任务不会自动授权。

## 三、企业核对与通知

1. 用同环境且属于目标岗位的企业账号登录。学生/企业建议用独立浏览器配置，不用普通标签页假设Cookie隔离。
2. 进入“我的岗位”及已授权投递，选择目标学生；查看岗位要求和固定快照。学生新版不会覆盖该报告。
3. 可筛选或对照两位已授权合成人物；筛选外保留的报告有明确提示。核对来源时关注项目、版本及行号。
4. 在**评审专属合成环境**可填写一条站内问题，核对收件人再确认发送；回学生通知查看对应投递。不要发邮件或联系真实收件人。
5. 需要体验撤回时只撤回本次合成投递，再验证旧访问拒绝。重新分享需新授权；线下下载副本无法追回。

## 四、看AI证据时辨别模式

- 当前隔离环境禁用外部模型，规则报告不是DeepSeek生成结果。
- 历史真实五项报告显示模型主动停止；另一单要求批次完成真实补取。二者有不同原始记录，不是一条五项成功工具链。
- Mock样例只演示分支和布局，页面应有标识。
- 一位独立人员的三例评审已收，两处理由仍待本人澄清；结构校验和自动测试不等于语义全对。

## 五、场景入口卡（准备者按实际生成值填写）

|字段|交付值/处理|
|---|---|
|网址与接受版本|待任务A完成后同步；由团队填写专属环境实际地址|
|学生/企业账号|私下提供，不写公开材料|
|岗位/报告/补证任务/投递|根据本次实际创建映射；不得复制作者旧ID假装新库已存在|
|材料与模式|校园报名固定V1/V2；规则或带日期的历史AI记录分别标识|
|异常恢复|保留原目录/配置/存储/数据库重启；不重播种、不清库|

首次使用卡住时，请记录停在哪一步、屏幕提示、是否求助以及恢复方法。不要为通过体验而由开发者持续代操作。真实200%缩放和草稿离窗尚待补验，遇到问题可作为独立反馈。
