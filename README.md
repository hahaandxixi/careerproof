## 一键生产模式启动（PowerShell）

首次安装依赖按 [干净环境复现流程](docs/本地复现流程.md) 执行，然后在本文件所在目录运行：

```powershell
.\Start-Local.ps1 -CheckOnly
.\Start-Local.ps1
# 演示结束；停止本脚本启动的服务，数据库数据卷保留
.\Stop-Local.ps1 -Database
```

`-SkipBuild` 仅用于已有当前生产构建的情况。
Node 不在 PATH 时传 `-NodePath '本机node.exe的绝对路径'`。启动脚本会检查端口、等待数据库、执行迁移、
构建前端并检查两个服务的健康状态；进程记录和日志位于被 Git 忽略的 `backend/.tmp/local-run/`。

比赛演示可直接双击 `Start-Demo.cmd`：它只按 AI 链路启动，初始化演示账号与九个岗位并打开演示页。
启动前会检查本地 `.env` 已明确启用 DeepSeek，但不会打印或修改 Key。PowerShell 用户也可运行
`.\Start-Demo.ps1`，并用 `.\Start-Demo.ps1 -CheckOnly` 仅做启动前检查。规则只在模型不可用或输出未通过校验时被动兜底。

## 本机启动（CMD）

先打开 Docker Desktop，等待引擎运行。下面适用于命令提示符 `cmd.exe`，不是 PowerShell。
已安装依赖的电脑打开两个终端分别执行；不要在数据库容器未就绪时启动后端。

后端终端：

```bat
cd /d "D:\jbcode\web ai\jianli\backend"
docker compose up -d --wait postgres
.venv\Scripts\alembic.exe upgrade head
.venv\Scripts\uvicorn.exe app.main:app --reload --host 127.0.0.1 --port 8000
```

前端终端：

```bat
cd /d "D:\jbcode\web ai\jianli\jianli"
npm run dev
```

浏览器访问 `http://127.0.0.1:3000`；接口文档在 `http://127.0.0.1:8000/docs`。
统一使用 `127.0.0.1`，不要与 `localhost` 来回切换以免造成 Cookie 会话混淆。
首次安装、环境变量和测试说明见 [后端说明](backend/README.md) 与 [前端说明](jianli/README.md)。

## 一次完整体验

1. 注册企业账号，创建企业组织，新增含能力要求的岗位并发布。
2. 退出后注册/登录学生账号，在「我的材料」上传简历及项目 ZIP 或作品 PDF/DOCX/TXT。
3. 等待解析完成，打开材料预览确认提取的文本；失败任务可重试，扫描 PDF 和常见图片由本地 OCR 识别，结果需对照原图复核。
4. 在岗位列表按方向、城市、类型筛选，进入岗位后选择本人的材料版本并发起分析。
5. 在 SSE 任务页查看检索、受控补检索、模型分析、引用校验和保存阶段，再核对逐项解释、引用、缺口与建议。
6. 上传新的项目版本后，旧报告仍指向当时的材料版本；企业账号不能自动读取学生私有报告。

## 本轮完成范围

- 真实岗位与已上传材料接通，权限由后端检查，不依赖前端隐藏按钮。
- 证据区分代码实现、依赖配置、简历声明；TODO、注释和说明文档不直接作为代码实现。
- 后台解析有并发上限、独立子进程硬超时、租期恢复、失败重试和重复运行保护。
- 分类入口扩展为软件开发、数据分析、运营、设计、其他；先完成运营文档评价试点。
- 外部模型采用严格 JSON 合约；要求编号、引用编号和结论边界均由后端校验，异常时保留规则结论。
- 模型最多发起一次 `retrieve_more_evidence`，执行器只访问当前上传版本的已索引片段，非法调用会被拒绝并留痕。
- 扫描 PDF 和图片通过本地 RapidOCR 转换为带置信度标记的文本，不外发原图。
- 固定 AI 评测覆盖无证据、部分证据、暂不支持、提示注入和正常引用，并记录 token 与延迟。

分类不等于评价能力全覆盖。不支持的技能显示「暂不支持评估」，不按零能力处理。
目前分数表示规则识别到的材料支持度，不能证明作者身份、熟练度或录用概率。

## 后续比赛工作

软件开发岗位的规则检索、职业推荐、模型证据解释、受控 Function Calling、引用校验、SSE、人工复核和降级链路已形成。产品按 AI 链路启动，本地规则只在模型不可用、达到限额或输出未通过校验时被动兜底。DeepSeek 固定难例已获得 8 份正文并暴露稳定的单括号格式缺陷；完整生产 API 报告已原生返回有效 JSON，工具执行后的完整报告及职业推荐的桌面与390px浏览器链路均已通过。下一步是独立人工语义评测、模型不可用时的浏览器降级复验和正式提交材料；OCR浏览器录制仅在视频展示该能力时补做。
语音面试、更多供应商和更多专业评价器继续延后，避免稀释主链路。在线部署是可选加分项。

仓库发布前检查 `.env`、上传目录和真实简历不会被提交；独立仓库从 2026-09-17 的真实基线开始保存提交记录，不回填历史。尚未创建或推送远程仓库。
