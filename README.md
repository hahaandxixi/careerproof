# 职证 CareerProof

CareerProof 是面向学生证据成长与企业岗位定义的 AI Web 应用。学生上传简历和项目，核对带来源引用的岗位分析、职业建议与补证任务；企业从岗位原文生成待确认要求，确认后发布。

## 当前实现与边界

Next.js / TypeScript 前端、FastAPI / Python 后端、PostgreSQL、本地文件存储。所有产品外部生成统一使用 DeepSeek 官方 API，文字与截图共用本地配置的 Key；不使用网页转接。API Key 不进入前端或仓库。

规则先检索候选证据并确定引用范围与评级上限，DeepSeek 在边界内解释证据、初评和规划补证。最多两轮受控规划可访问当前冻结材料与本人历史上下文；历史判断不能替代当前证据。输出经过引用和表达校验，故障、无证据或限额触发被动兜底，用户没有主动规则模式。

截图观察和本地 OCR 分开记录。截图不能证明本人贡献、真实部署或持续运行，不自动赋实践等级。学生本人采纳材料也不等于独立人工语义复核。企业发布岗位不会获得学生私有材料或报告访问权。

已实现、已验收与待验证范围，以 [DeepSeek 统一路线与能力矩阵](docs/guides/AI与数据边界.md) 为准；测试数量、旧供应商尝试与失败案例保留在 [历史归档](docs/archive/README.md)，不作为当前配置说明。

## 本地启动

首次安装按 [本地复现流程](docs/guides/使用与启动.md) 准备依赖与本地配置。启动 Docker Desktop 后，在仓库目录运行：

```powershell
.\Start-Local.ps1 -CheckOnly
.\Start-Local.ps1
# 强制重建 / 仅构建（不启动、不迁移）
.\Start-Local.ps1 -Rebuild
.\Start-Local.ps1 -BuildOnly
# 只停止网站；共用数据库继续运行
.\Stop-Local.ps1
# 确认数据库不再被其他验收服务使用时再停止
.\Stop-Local.ps1 -Database
```

课堂演示双击 `Start-Demo.cmd`，停止双击 `Stop-Demo.cmd`（默认只停网站）。命令行可传 `-CheckOnly`、`-Rebuild`、`-NoBrowser`，停止入口支持 `-Database`。启动自动选择通过版本与源码核验的本地依赖环境；不自动安装或修改配置。源码/资源/锁文件未变时复用已有生产构建，重复启动只复用已确认归属、配置与代码一致的健康服务。初始化完成的同一演示运行不重复播种，必要时用 `-Reseed`。

账号信息从本机未入库的 `backend/.tmp/demo-credentials.json` 读取；不要将合成演示账号用于真实个人材料或公网部署。修改凭据文件不会轮换数据库中已有账号的密码或撤销旧会话。

访问 `http://127.0.0.1:3000`，接口说明在 `http://127.0.0.1:8000/docs`。统一使用 `127.0.0.1`，避免与 `localhost` 混用会话。启动日志与进程记录在 `backend/.tmp/local-run/`；已有运行记录时先按完整手册检查并停止原服务。
